# 📋 Simple Attendance System (PHP & MySQL)

This project is a lightweight web application designed to manage and record employee attendance. It serves as a practical implementation of web development fundamentals using PHP and MySQL.

## ✨ Features
* **Attendance Form:** Easy-to-use interface for entering employee names and status (Present, Permission, Sick).
* **Database Management:** Automatically stores records into a MySQL database.
* **Attendance Report:** A dedicated page to view and track all attendance history in real-time.
* **Modern UI:** Styled with clean CSS for a better user experience.

## 🛠️ Tech Stack
* **Backend:** PHP (Native)
* **Database:** MySQL
* **Web Server:** XAMPP / Apache
* **Frontend:** HTML5, CSS3

## ⚙️ How to Setup
1. **Download/Clone** this repository to your local machine.
2. **Copy the folder** into your XAMPP `htdocs` directory.
3. **Database Configuration:**
   * Open **phpMyAdmin**.
   * Create a new database named `db_attendance`.
   * Create a table named `data_absensi` with the required columns (ID, Name, Status, Time).
4. **Access the Application:** Open your browser and navigate to `localhost/attendance_system/index.php`.
